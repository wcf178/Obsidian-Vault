laravel路由的中间件链路是洋葱结构的. 例如请求经过中间件A-B-C之后进入控制器得到response返回response的时候, 会按照逆序依次经过中间件C-B-A

如图  [[路由中间件请求链路图]]


例:
中间件

```php
public function handle($request, Closure $next)
{
    echo '1';

    $response = $next($request);

    echo '2';

    return $response;
}
```

控制器:

```php
public function index()
{
    echo '3';

    return response('Hello');
}
```

得到的输出:  132
