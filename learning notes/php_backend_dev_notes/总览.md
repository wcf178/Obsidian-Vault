# 今晚面试前最后1小时优先级

如果时间不够，按这个顺序复习：

1. MySQL索引 + MVCC + 锁
2. Redis缓存三大问题 + 分布式锁
3. Laravel IOC + 生命周期
4. MQ幂等 + 消息可靠性
5. Linux排查命令
6. Nginx与PHP-FPM
7. 设计模式
8. PHP底层（引用计数、GC）

对于你这种做跨境电商 PHP 后端的经历，我判断面试官最可能深挖的是：

- MySQL索引优化与慢SQL分析
- Redis缓存设计
- Laravel架构设计
- 队列与异步任务
- 高并发订单/库存/调价场景
- 数据库分库分表思路
- 实际项目中的性能优化案例

这几个模块占面试命中率的 80% 以上。
